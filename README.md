# YouTube Clone

A YouTube-inspired frontend website created using only HTML5 and CSS3. This project was built to practice website layouts, navigation bars, sidebars, video sections, and CSS styling.

## 🚀 Features

- YouTube-style navigation bar
- Search bar
- Sidebar navigation
- Video categories
- Video cards
- Embedded videos
- Create and notification icons
- Clean and simple UI
- Responsive layout

## 🛠️ Technologies Used

- HTML5
- CSS3
